# Internacionalização (i18n)

Este documento descreve a implementação de internacionalização (i18n) no projeto Ecommerce Dashboard.

## Visão Geral

O projeto implementa internacionalização usando um contexto React personalizado, permitindo que a aplicação seja exibida em diferentes idiomas. Atualmente, suportamos três idiomas:

- Inglês (en)
- Espanhol (es)
- Português (pt)

## Implementação

### 1. Contexto de Idioma

O contexto de idioma é implementado em `@/components/i18n/language-context.tsx`:

\`\`\`typescript
"use client"

import { createContext, useContext, useState, useEffect, type ReactNode } from "react"

type Language = "en" | "es" | "pt"

// Definições de tradução inline
const translations = {
  en: {
    common: {
      notifications: "Notifications",
      // Mais traduções...
    },
    dashboard: {
      welcome: "Welcome to Synergy,",
      // Mais traduções...
    },
    // Mais seções...
  },
  es: {
    // Traduções em espanhol...
  },
  pt: {
    // Traduções em português...
  },
}

type Translations = typeof translations.en

interface LanguageContextType {
  language: Language
  setLanguage: (lang: Language) => void
  t: Translations
}

const LanguageContext = createContext<LanguageContextType | undefined>(undefined)

export function useLanguage() {
  const context = useContext(LanguageContext)
  if (!context) {
    throw new Error("useLanguage must be used within a LanguageProvider")
  }
  return context
}

export function LanguageProvider({ children }: { children: ReactNode }) {
  const [language, setLanguageState] = useState<Language>("pt")
  const [t, setTranslations] = useState<Translations>(translations.pt)

  useEffect(() => {
    // Verificar se há uma preferência de idioma salva
    const savedLanguage = localStorage.getItem("language") as Language
    if (savedLanguage && ["en", "es", "pt"].includes(savedLanguage)) {
      setLanguageState(savedLanguage)
      setTranslations(translations[savedLanguage])
    } else {
      // Detectar idioma do navegador, mas usar pt como fallback
      const browserLang = navigator.language.split("-")[0] as Language
      if (["en", "es", "pt"].includes(browserLang)) {
        setLanguageState(browserLang)
        setTranslations(translations[browserLang])
      } else {
        // Usar pt como padrão se o idioma do navegador não for suportado
        setLanguageState("pt")
        setTranslations(translations.pt)
      }
    }
  }, [])

  const setLanguage = (lang: Language) => {
    setLanguageState(lang)
    setTranslations(translations[lang])
    localStorage.setItem("language", lang)
  }

  return <LanguageContext.Provider value={{ language, setLanguage, t }}>{children}</LanguageContext.Provider>
}
\`\`\`

### 4. Formatação de Dados

Para formatar dados de acordo com o idioma, usamos funções de formatação em `@/utils/format.ts`:

\`\`\`typescript
import { format, formatDistanceToNow } from "date-fns"
import { ptBR, es, enUS } from "date-fns/locale"

type Locale = "pt" | "es" | "en"

// Mapeamento de locales para date-fns
const locales = {
  pt: ptBR,
  es: es,
  en: enUS,
}

// Formatar números
export function formatNumber(value: number, locale: Locale, options?: Intl.NumberFormatOptions): string {
  return new Intl.NumberFormat(getFullLocale(locale), options).format(value)
}

// Formatar moeda
export function formatCurrency(value: number, locale: Locale, options?: Intl.NumberFormatOptions): string {
  const defaultOptions = {
    style: "currency",
    currency: locale === "en" ? "USD" : locale === "es" ? "EUR" : "BRL",
  }
  
  return new Intl.NumberFormat(getFullLocale(locale), { ...defaultOptions, ...options }).format(value)
}

// Formatar data
export function formatDate(date: Date, locale: Locale, formatType: "short" | "medium" | "long" = "medium"): string {
  const formatStr = {
    short: locale === "en" ? "MM/dd/yyyy" : "dd/MM/yyyy",
    medium: locale === "en" ? "MMM d, yyyy" : "d 'de' MMM 'de' yyyy",
    long: locale === "en" ? "MMMM d, yyyy" : "d 'de' MMMM 'de' yyyy",
  }[formatType]
  
  return format(date, formatStr, { locale: locales[locale] })
}

// Formatar tempo relativo
export function formatTimeAgo(date: Date, locale: Locale): string {
  return formatDistanceToNow(date, {
    locale: locales[locale],
    addSuffix: true,
  })
}

// Obter código de locale completo
function getFullLocale(locale: Locale): string {
  switch (locale) {
    case "pt":
      return "pt-BR"
    case "es":
      return "es-ES"
    case "en":
    default:
      return "en-US"
  }
}

## Detecção de Idioma

A detecção de idioma segue esta ordem de prioridade:

1. Preferência salva no localStorage
2. Idioma do navegador (se suportado)
3. Português como fallback

\`\`\`typescript
useEffect(() => {
  // 1. Verificar localStorage
  const savedLanguage = localStorage.getItem("language") as Language
  if (savedLanguage && ["en", "es", "pt"].includes(savedLanguage)) {
    setLanguageState(savedLanguage)
    setTranslations(translations[savedLanguage])
  } else {
    // 2. Verificar idioma do navegador
    const browserLang = navigator.language.split("-")[0] as Language
    if (["en", "es", "pt"].includes(browserLang)) {
      setLanguageState(browserLang)
      setTranslations(translations[browserLang])
    } else {
      // 3. Usar português como fallback
      setLanguageState("pt")
      setTranslations(translations.pt)
    }
  }
}, [])

## Boas Práticas

### 1. Chaves de Tradução Consistentes

Mantenha as chaves de tradução consistentes entre os idiomas:

\`\`\`typescript
// Bom: Mesmas chaves em todos os idiomas
en: {
  common: {
    submit: "Submit",
  }
},
es: {
  common: {
    submit: "Enviar",
  }
},
pt: {
  common: {
    submit: "Enviar",
  }
}

// Ruim: Chaves inconsistentes
en: {
  common: {
    submit: "Submit",
  }
},
es: {
  common: {
    send: "Enviar", // Chave diferente!
  }
}
\`\`\`

### 2. Valores Padrão

Forneça valores padrão para evitar erros quando uma tradução estiver faltando:

\`\`\`typescript
function Button({ label }: { label: string }) {
  const { t } = useLanguage()
  
  // Usar o valor passado ou buscar da tradução com fallback
  const buttonText = label || t.common.submit || "Submit"
  
  return <button>{buttonText}</button>
}
\`\`\`

### 3. Pluralização

Para pluralização, use funções auxiliares:

\`\`\`typescript
function pluralize(count: number, singular: string, plural: string): string {
  return count === 1 ? singular : plural
}

function ItemCount({ count }: { count: number }) {
  const { language, t } = useLanguage()
  
  const itemText = language === "en"
    ? pluralize(count, "item", "items")
    : language === "es"
    ? pluralize(count, "elemento", "elementos")
    : pluralize(count, "item", "itens")
  
  return <span>{count} {itemText}</span>
}

## Conclusão

A implementação de internacionalização no projeto Ecommerce Dashboard permite que a aplicação seja usada por pessoas de diferentes idiomas. A abordagem baseada em contexto React torna fácil adicionar novos idiomas e usar traduções em qualquer componente.

Para adicionar suporte a um novo idioma:

1. Adicione as traduções ao objeto `translations`
2. Adicione o novo idioma ao tipo `Language`
3. Adicione o mapeamento de locale para date-fns
4. Adicione a bandeira do país ao objeto `flags`
5. Adicione o novo idioma ao seletor de idioma

Seguindo estas diretrizes, podemos manter uma aplicação multilíngue consistente e fácil de usar.
